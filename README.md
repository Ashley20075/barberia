-Crear Superusuario (Admin): python manage.py createsuperuser
-Enviar Recordatorios: python manage.py enviar_recordatorios
-Aplicar Migraciones: python manage.py makemigrations / python manage.py migrate
-Iniciar Servidor: python manage.py runserver

-Inicio Rápido (Automatizado)
 -En Windows:  ejecutar.bat
 -En Mac / Linux: Otorga permisos de ejecución (solo la primera vez)
  chmod +x ejecutar.sh
    ./ejecutar.sh
